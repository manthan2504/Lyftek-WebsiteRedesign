# components/ui

Small, generic, highly-reusable primitives with no business meaning of their own: Button, Input, Badge, Card shell, Textarea, Checkbox, Radio, etc.

Rules (17_CODING_STANDARDS.md):

- Typed props, no hidden side effects, self-contained.
- If a variant is needed, document it (purpose, when to use / not use) rather than forking a new component.
- These map to `09_DESIGN_SYSTEM.md`'s component library — update that doc when a component here is added or its contract changes.
